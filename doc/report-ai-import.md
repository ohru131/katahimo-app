# 日報AIの設定ファイル取込

法人が持っているキーワード表・年齢帯表・判定基準・言い回し集・プロンプト文面(xlsx/xls/csv)を、
設定モーダル「日報AIの調整(3軸)」の「取込」タブから読み込み、テナントの設定にマージする機能。
3軸の意味(年齢帯・教育関心度★・ストレス度PSI)は `doc/db/new-domains.md` 第6章、契約(zod)は
`packages/shared/src/contracts/reportAiAdmin.ts`、変換ロジックは
`packages/shared/src/reportAiImport.ts` を参照。

## 取込の流れ

1. 「取込」タブでファイル(xlsx/xls/csv)を選ぶと、ブラウザ側(SheetJS)が全シートを読む。
2. `parseReportAiImportSheets` が各シートの1行目(見出し)を下記の別名表と突き合わせ、
   シートの種類(年齢帯・キーワード・教育関心度★・ストレス度・表現・プロンプト文面)を判定する。
   どの種類にも当てはまらないシートは取り込まず、警告に出す。
3. 種類ごとに2行目以降を読み、値をスキーマ(`contracts/reportAiAdmin.ts`)で検証する。
   読み取れなかった・検証に通らなかった行は、その行だけを警告に出して捨てる
   (1行の入力ミスで表全体の取込が失敗しないようにするため)。
4. 画面に取込件数と警告の一覧をプレビュー表示する。内容を確認して確定すると
   `POST /api/settings/admin/report-ai/import` に送り、テナントの設定へマージする。

シートの判定は**シート名ではなく見出し行**で行う。法人の資料はシート名が自由
(「キーワード表(最新)」「Sheet3」等)なため、名前をあてにすると取込のたびに人が
シート名を直すことになる。同じ種類のシートが複数あっても(月齢別に分けている資料など)、
出てきた順に行を積み重ねる。

見出しの読み取りは、全角/半角(NFKC)を揃え・英字を小文字にし・区切り記号と空白を落として
比べる(`normalizeHeader`)。「対象月齢(から)」と「対象月齢(から)」(全角括弧)と
「age_from_months」は同じ列として扱われる。

## マージの規則

取込は**マージ**であって全件入れ替えではない。

- 年齢帯・キーワード・教育関心度★・ストレス度は `code`(年齢帯・キーワード)または `level`(各レベル)
  で upsert する。表に載っていない既存の行は消さない。
- 年齢帯どうしの月齢の重なりは、取込後の姿(既存の行 + 今回の行)でまとめて検査する
  (1件ずつ順に見ると、「0〜12ヶ月」を「0〜6」「6〜12」に分割する取込のような、
  入れ替えの途中経過だけを見て重なったと誤判定してしまうため)。重なりがあれば取込全体を
  拒否する。
- キーワードの `ageBandCodes`(相性の良い年齢帯)は、既存の年齢帯 + 今回取り込む年齢帯の
  コード集合に含まれている必要がある。存在しないコードを指す行はエラーにする(黙って落とさない)。
- 温かみ表現・避ける表現(`report_phrases`)には一意制約となる自然キーが無いため、
  取込側が `(kind, body)` の組で既存行を読んでから、一致すれば更新・無ければ追加と振り分ける
  (`upsertPhrasesByBody`)。同じ資料を2回取り込んでも重複した表現が増えない。
- プロンプト文面は「いま有効な版と本文が違うときだけ」新しい版を積む(`note='取込'`)。
  同じ文面のまま2回取り込んでも版の履歴が汚れない。
- 反映の順序は 年齢帯 → 教育関心度★・ストレス度 → キーワード → 表現 → プロンプト文面。
  キーワードが年齢帯コードを参照するため年齢帯を先に、プロンプト文面は版を積む操作なので
  最後に反映する(前段の検証で落ちたときに版だけ増えるのを避けるため)。

反映は表ごとに順に行い、取込全体を1つのトランザクションでは囲んでいない。途中で失敗した場合は
前半だけが反映された状態で止まる。ただし取込はマージ(`code` / `level` で更新)なので、
原因を直して同じファイルをもう一度取り込めば、既に入っている行は同じ値で上書きされ、
残りが入って揃う。

## 値の解釈

### 年齢表記 → 月齢の半開区間

「6〜12ヶ月」「1歳」「0-6」「1歳〜2歳」「3歳以上」などの自由な年齢表記を、月齢の半開区間
`[from, to)` に変換する(`parseAgeRangeText`)。

- 単位(歳/ヶ月とその表記ゆれ。ヶ/ケ/箇/か/カ)を見て、月齢に換算する。
- 範囲の区切り(`〜` `~` `-` など)は1種類に正規化してから両端を読む。
- 片側にしか単位が無ければ、もう一方の単位で読む。「1-2歳」も「1歳-2」も `[12, 36)`。
- **年で書かれた上限はその年の終わりまで含める。** 「1歳〜2歳」は日本語では「2歳の子まで」を
  指すため、上限は2歳の終わり=36ヶ月。一方「6〜12ヶ月」は月齢で書かれており、12ヶ月ちょうどは
  次の帯(1歳)に入る=上限は12ヶ月。単位によって上限の解釈が変わる。
- 「◯歳以上」「◯以降」は上限144ヶ月(`AGE_MONTHS_MAX`)まで、「◯ヶ月未満」「◯より前」は
  下限0ヶ月からとして扱う。
- 単独の表記(範囲でない)は1区切りぶんとして扱う。「1歳」= `[12, 24)`、「6ヶ月」= `[6, 7)`。
- 変換できなければ(判定できない表記、幅が0以下になった場合を含め)その行は取り込まない。

### 教育関心度★・ストレス度の書き方

「★3」「3」「★★★」のいずれの書き方でもレベル(1〜5)として読む(`parseStarLevel`)。範囲外・
判定不能な値は捨てる。キーワードの★範囲を1列で書く場合(「★3〜★5」「3-5」「3以上」)も
同じ関数で両端を読む(`parseLevelRange`)。

### ○×の書き方

「○/◯/〇/◎/✓/✔/はい/可/有/あり/使用可/利用可/yes/y/true/1」は真、
「×/✕/✗/x/✘/いいえ/不可/無/なし/使用不可/利用不可/no/n/false/0/-」は偽として読む(`parseBooleanCell`)。
どちらにも当てはまらなければ列が無いものとして既定値を使う。

## GAS版「ＡＩプロンプト」シートの取込

GAS版の「ＡＩプロンプト」シート(見出し `Key` / `Prompt Template`)をそのまま取り込める。
GAS版のキー(`PROMPT_KEYS`)から本アプリのキーへの対応は次のとおり(`GAS_PROMPT_KEY_MAP`)。

| GAS版のキー | 本アプリのキー |
|---|---|
| `GenerateWithWarnings` | `daily_report` |
| `GenerateAccident` | `accident_report` |
| `PlaceholderDaily` | `daily_memo_placeholder` |
| `PlaceholderAccident` | `accident_memo_placeholder` |
| `HintAccident` | `accident_hint` |
| `PlaceholderHiyari` | `hiyari_hint` |

本アプリのキー(`daily_report` 等。`daily_report_stance` / `receipt_ocr` を含む)で書かれた表も
そのまま読める。対応の無いキーは警告に出して取り込まない。

## 取込手順(管理画面)

1. 管理者としてログインし、設定モーダルを開く。
2. 「AIプロンプト」ではなく「🧩 日報AIの調整(3軸)」を開く(`ReportAiAdminModal`)。
3. 「取込」タブでxlsx/xls/csvファイルを選ぶ。
4. 取込件数・警告のプレビューを確認する。無視されたシート・捨てられた行があれば、
   警告にその理由(シート名・行番号・原因)が日本語で出るので、元の表を直して読み込み直す。
5. 内容を確認して確定すると、テナントの設定にマージされる(既存の設定は消えない)。
